GitHub Release Monitor — 便携版使用说明
=====================================

一、启动
  双击「启动监控.bat」。
  浏览器会自动打开 http://127.0.0.1:3000
  （如果不自动打开，手动访问该地址即可）

二、首次初始化（只需一次）
  首次启动时，黑色窗口会显示一行「Setup token」，
  同时保存在 data\setup-token.txt。
  在打开的页面中按提示创建管理员账号（粘贴该 token）。

三、日常使用
  - 每次只需双击「启动监控.bat」，关掉窗口即退出程序。
  - 监控的仓库、设置、账号全部保存在 app\data 目录（本机数据，
    不上传任何云端）。
  - 修改端口：设置环境变量 GRM_PORT 后再启动，例如
      set GRM_PORT=3210 && 启动监控.bat

四、目录结构
  node\       Node.js 运行时（免安装）
  app\        程序本体与本机数据（data\）
  启动监控.bat

五、更新
  到本项目的 GitHub Releases 下载新版本 zip，
  解压覆盖旧目录即可（app\data 会保留你的数据，
    建议解压前备份 app\data）。
